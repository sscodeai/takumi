# jp-detailed-design

日本企業ソフトウェア開発の詳細設計（Detailed Design）スキル。
基本設計書を入力とし、実装者がそのままコーディングできる粒度まで落とし込む。

## Output（詳細設計書の構成）

1. **画面仕様** — 画面ごとのレイアウト・入力項目・バリデーション・イベント
2. **API 仕様** — エンドポイントごとの リクエスト/レスポンス/エラーコード/権限
3. **DB スキーマ** — テーブル定義・カラム・型・制約・インデックス・シーケンス
4. **クラス/モジュール設計** — 責務・主要メソッド・依存関係
5. **単体テスト仕様** — テストケース一覧（正常系/異常系/境界値）
6. **実装手順** — ステップバイステップの実装ガイド

## 品質基準

- 実装者が設計書だけでコードを書ける具体的さ（曖昧な記述禁止）
- テストケースは 正常系 / 異常系 / 境界値 を網羅
- 非機能要件（性能・セキュリティ）への言及
