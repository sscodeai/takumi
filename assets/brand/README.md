# Takumi Brand Assets

Takumi's mark combines three ideas:

- **T-shaped platform core**: Takumi is the orchestration layer, not a single agent.
- **Workflow nodes**: requirements, design, tests, and evidence stay connected by traceability.
- **Verification check**: agent claims do not complete work; independent evidence does.

## Files

- `takumi-logo.svg`: horizontal logo with wordmark and tagline.
- `takumi-icon.svg`: square icon for GitHub, favicons, and compact surfaces.

## Palette

- Ink: `#111827`
- Paper: `#F8FAFC`
- Trace: `#2DD4BF`
- Verify: `#F97316`
- Text secondary: `#475569`

## Usage

Use the icon where the available space is square or compact. Use the horizontal logo for README headers, documentation pages, and presentation title slides.
