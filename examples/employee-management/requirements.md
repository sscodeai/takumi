# 社員管理システム要件定義書

## 1. 概要
社員情報を管理する Web システム。管理者が社員の登録・更新・削除を行い、一般ユーザーは自身の情報を閲覧・一部編集できる。

## 2. 機能要件

### 2.1 認証
- 社員はユーザーIDとパスワードでログインする
- ログイン失敗時にエラーメッセージを表示する
- セッションタイムアウトは 30 分

### 2.2 社員管理（管理者）
- 社員の新規登録（氏名、メール、部署、役職、入社日）
- 社員情報の更新・削除
- 社員一覧の検索（氏名、部署、入社日範囲）
- 削除は論理削除とする

### 2.3 権限
- ロール: admin / manager / member
- admin は全機能アクセス可
- manager は自部署の社員のみ管理可
- member は自身の情報のみ閲覧可

### 2.4 入力検証
- 氏名: 必須、最大 50 文字
- メール: 必須、形式チェック
- 入社日: 必須、未来日付不可

## 3. 非機能要件
- 同時接続 100 ユーザーで応答 2 秒以内
- パスワードはハッシュ化保存（bcrypt）
- 操作ログ（監査証跡）を保存する

## 4. 制約
- バックエンド: Spring Boot 3 (Java 17) または Node.js
- DB: PostgreSQL
- フロントエンド: シンプルな HTML/JS（SPA は不要）
