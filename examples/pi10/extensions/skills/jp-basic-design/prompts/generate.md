## 出力形式（Markdown）

```markdown
# 基本設計書

## 1. システム概要
（本文）

## 2. アーキテクチャ
（構成・技術選定・理由）

## 3. 画面一覧
| 画面ID | 画面名 | 概要 | 要件 |

## 4. API 一覧
| API ID | メソッド | パス | 入力 | 出力 | 要件 |

## 5. DB 設計
（テーブル一覧・ER 関係）

## 6. 権限設計
（ロール・権限マトリクス）

## 7. 入力検証
（検証ルール一覧）

## 8. 例外処理
（エラーコード・ハンドリング方針）

## 9. 外部インターフェース
（連携システム一覧）

## 10. 非機能要件
（性能・セキュリティ・可用性）
```

## ルール

1. 各セクションに由来要件を `（REQ-xxx）` 形式で明記する
2. 全 REQ が設計書にマッピングされていること
3. 推測のみの内容には「要確認」と明記する
4. 出力は Markdown 形式（Excel 出力は将来フェーズ）
